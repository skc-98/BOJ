# 알고리즘 복기 공부 순서
1. **기초 구현·복잡도** — 입출력, 배열, 문자열, 반복문, Big-O
2. **기본 자료구조** — 리스트, 스택, 큐, 덱, 해시맵·해시셋
3. **정렬** — 기본 정렬, 사용자 정의 정렬, 비교 기준
4. **완전 탐색** — 브루트포스, 재귀, 순열·조합, 백트래킹
5. **배열·구간 탐색** — 누적 합, 투 포인터, 슬라이딩 윈도우
6. **이분 탐색** — 경계 찾기, 매개변수 탐색
7. **그래프·트리 탐색** — 그래프 표현, DFS, BFS, 트리 순회
8. **그리디** — 선택 기준, 정당성 검증, 우선순위 큐 활용
9. **동적 계획법(DP)** — 상태 정의, 점화식, 초기값, 메모이제이션
10. **심화 그래프** — 최단 경로, 유니온 파인드, MST, 위상 정렬
