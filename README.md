1. **기초 구현** — 입출력, 배열, 문자열, 반복문

3. **기본 자료구조** — 리스트, 스택, 큐, 덱, 해시

5. **완전 탐색** — 브루트포스, 재귀, 백트래킹

8. **그리디** — 선택 기준과 정당성 이해
9. **동적 계획법(DP)** — 상태 정의, 점화식, 초기값
